title: Find which layer a shape is on

faq: true

要查找形状所在的图层，您需要打开_图层_对话框。

1. 选择_视图 > 图层_以打开_图层_对话框（如果尚未打开）。
2. 选择形状，然后在_图层_对话框中单击_将选择移动到_图标（带有向下箭头的框）。

旁边有勾选标记的图层就是形状所在的图层。
