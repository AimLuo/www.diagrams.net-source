draw.io 的桌面版本是一个独立应用程序，不会将任何数据发送到设备外部。

虽然 draw.io 不支持 ``.vsd``、``.vdx`` 和 ``.vss`` 导入，但您可以先转换为现代 ``.vsdx`` 格式，然后通过我们在 [app.diagrams.net](https://app.diagrams.net/) 的免费 Web 应用程序转换为 draw.io。

**转换为 ``.vsdx`` 图表：** 在正常的 Microsoft 编辑器（2013 或更高版本）中打开图表文件，并将其另存为 ``.vsdx`` 文件。创建新的 draw.io 图表，然后将 ``.vsdx`` 文件拖放到图表编辑器中。

## 将 .vsdx 图表文件转换为 .drawio

1. 转到[我们的在线编辑器](https://app.diagrams.net)
2. 将 ``.vsdx`` 文件拖放到绘图画布上，draw.io 将自动导入它。
3. 从菜单中选择_文件 > 保存_，必要时更改文件名，然后选择_设备_作为目标。
4. 在 draw.io Desktop 应用程序中正常打开 ``.drawio`` 图表文件。
